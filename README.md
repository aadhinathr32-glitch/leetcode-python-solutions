## Python Approaches

### 1888 — Minimum Number of Flips to Make the Binary String Alternating

Consider both possible alternating patterns: `010101...` and `101010...`. Because type-1 operations rotate the string, double the string and use a sliding window of length `n` to represent every possible rotation. Maintain the number of mismatches with each pattern inside the current window and take the minimum mismatch count.

- **Time:** O(n)
- **Auxiliary space:** O(n), for the doubled string


### 973 — K Closest Points to Origin

Sort the points by their squared distance from the origin, calculated as `x² + y²`. The square root is unnecessary because comparing squared distances gives the same ordering as comparing actual Euclidean distances. After sorting, return the first `k` points.

- **Time:** O(n log n), for sorting the points
- **Auxiliary space:** O(log n), for Python's sorting implementation

### 1040 — Moving Stones Until Consecutive II

Sort the stone positions and use two pointers to find the largest group of stones that already fits inside a window of `n` positions. The stones outside that window determine the minimum moves. Handle the special case where `n-1` stones are consecutive and the remaining endpoint is too far away, which requires 2 moves. For the maximum, calculate the empty positions on either side while accounting for the endpoint restriction.

- **Time:** O(n log n)
- **Auxiliary space:** O(1) apart from sorting


### 2390 — Removing Stars From a String

Use a stack to simulate the removals. Add each normal character to the stack. When a `*` is encountered, pop the most recently added character because it is the closest non-star character to the left. After processing the string, join the remaining stack characters.

- **Time:** O(n)
- **Auxiliary space:** O(n)

## SQL Solutions

### 3705 — Find Golden Hour Customers

Group orders by customer and calculate the total number of orders, peak-hour orders, rated orders, and average rating. Peak hours are checked with `TIME(order_timestamp)` for 11:00–14:00 and 18:00–21:00. Use `COUNT(order_rating)` to measure rating completion while `AVG(order_rating)` ignores NULL ratings. The peak-hour percentage is rounded to the nearest whole number for the required output, while the average rating is rounded to 2 decimal places. Filter with `HAVING` for all four golden-hour criteria, then sort by average rating and customer ID in descending order.

- **Time:** O(n), where n is the number of orders
- **Auxiliary space:** O(c), where c is the number of customers in the grouped result

### 3521 — Find Product Recommendation Pairs

Self-join `ProductPurchases` on `user_id` to pair products bought by the same customer. Keep only pairs where the first product ID is smaller, join `ProductInfo` twice to retrieve both categories, group by the product pair, and retain pairs bought by at least three distinct customers. Sort by customer count descending, then product IDs ascending.

- **Time:** O(P²) in the worst case per customer’s purchases, where P is the total number of purchase rows; the join workload depends on how many products each customer purchased
- **Auxiliary space:** O(Q) for grouped product pairs, where Q is the number of distinct pairs generated

## Python Approaches

### 3144 — Minimum Substring Partition of Equal Character Frequency

Use dynamic programming. For each starting index, extend the substring one character at a time while maintaining character frequencies, the number of distinct characters, and the maximum frequency. A substring is balanced when `length == distinct * max_freq`, meaning every distinct character occurs exactly `max_freq` times. When a balanced substring is found, update the minimum partition count for its ending position.

- **Time:** O(n²)
- **Auxiliary space:** O(n)

### 641 — Design Circular Deque

Use a fixed-size array as a circular buffer. Keep `front` pointing to the first element, `rear` pointing to the next free position after the last element, and `count` tracking the current number of elements. Insertions and deletions update the corresponding pointer with modulo `size`, allowing the deque to wrap around without shifting elements. `isEmpty` and `isFull` are determined directly from `count`.

- **Time:** O(1) for every operation
- **Auxiliary space:** O(k), for the fixed-size circular buffer

### 1226 — The Dining Philosophers

Use one lock for each fork to ensure that a fork can be held by only one philosopher at a time. Map the left fork to `(philosopher + 1) % 5` and the right fork to `philosopher`. To prevent deadlock, even-numbered philosophers acquire their left fork first while odd-numbered philosophers acquire their right fork first, breaking the circular-wait condition. Once both locks are held, call the required pick, eat, and put callbacks, then release both fork locks.

- **Time:** O(1) per call, excluding the duration of `eat()`
- **Auxiliary space:** O(1), using five fork locks

### 2683 — Neighboring Bitwise XOR

XOR all values in `derived`. Every value in the original binary array appears exactly twice in the XOR expression, so the total must cancel to zero. Therefore, a valid `original` array exists exactly when the XOR of all elements in `derived` is zero.

- **Time:** O(n)
- **Auxiliary space:** O(1)

### 1218 — Longest Arithmetic Subsequence of Given Difference

Use a hash map to store the longest arithmetic subsequence ending at each value. For every number, look up `num - difference`. If it exists, extend that subsequence by one; otherwise start a new subsequence of length 1. Because the array is processed from left to right, the stored length automatically respects the subsequence order.

- **Time:** O(n)
- **Auxiliary space:** O(n)

### 3964 — Minimum Lights to Illuminate a Road

Use a difference array to track how many existing bulbs illuminate each position. For every working bulb, mark its illuminated range with a +1 at the start and a -1 just after the end. Then scan from left to right while maintaining the current coverage. Whenever a position is uncovered, install one additional bulb at the next position (i + 1), which covers the current position and extends two positions to the right. This greedy placement minimizes the number of additional bulbs.

- **Time:** O(n)
- **Auxiliary space:** O(n)

### 3153 — Sum of Digit Differences of All Pairs

Process each digit position independently. Count how many numbers have each digit at that position. If a digit occurs `c` times, it differs from the other `n - c` numbers in `c * (n - c)` ordered comparisons. Summing these values over all digits and dividing by 2 gives the number of unordered pairs.

- **Time:** O(n × d), where d is the number of digits
- **Auxiliary space:** O(1)

### 3192 — Minimum Operations to Make Binary Array Elements Equal to One II

Scan the array from left to right while tracking whether the current suffix has been flipped an odd number of times. The actual current value is `num ^ current_flip`. Whenever it is `0`, a flip is required at that index; increment the operation count and toggle the flip state. This greedy choice is necessary because once we pass an index, we cannot change it without flipping the suffix again.

- **Time:** O(n)
- **Auxiliary space:** O(1)

### 1958 — Check if Move is Legal

Check all 8 possible directions from the move position. In each direction, move through one or more opponent pieces and then verify that the next cell contains the player's own color. If such a sequence exists, the move forms a good line and is legal. Otherwise, check the remaining directions.

- **Time:** O(1)
- **Auxiliary space:** O(1)

### 2761 — Prime Pairs With Target Sum

Use the Sieve of Eratosthenes to precompute which numbers up to `n` are prime. Then check every possible `x` from 2 through `n // 2`; its matching value is `y = n - x`. If both are prime, add `[x, y]` to the result. Iterating `x` in increasing order automatically produces the required sorted pairs.

- **Time:** O(n log log n)
- **Auxiliary space:** O(n)

### 2121 — Intervals Between Identical Elements

Group the indices of each value. For each group, use a prefix sum of indices to calculate the total distance from the current index to all equal elements on the left and right in O(1). The left contribution is the current index times the number of earlier occurrences minus their index sum; the right contribution is the sum of later indices minus the current index times their count.

- **Time:** O(n)
- **Auxiliary space:** O(n)

### 1895 — Largest Magic Square

Build row and column prefix sums so any row or column sum inside a candidate square can be calculated in O(1). Try square sizes from largest to smallest. For each candidate, use the first row as the target sum, then verify every row, every column, and both diagonals. Return the first valid size because sizes are checked in descending order.

- **Time:** O(m × n × min(m, n))
- **Auxiliary space:** O(m × n)

### 2352 — Equal Row and Column Pairs

Store every row as a tuple in a frequency dictionary. Then build each column as a tuple and look up its frequency in the dictionary. Every matching frequency contributes that many row-column pairs.

- **Time:** O(n²)
- **Auxiliary space:** O(n²)

### 3587 — Minimum Adjacent Swaps to Alternate Parity

Collect the original indices of even and odd numbers. An alternating arrangement is possible only when the counts differ by at most one. For each possible starting parity, place that parity at target indices 0, 2, 4, ... and sum the absolute movements from the original positions to those targets. This movement equals the number of adjacent swaps needed. When one parity has more elements, it must be the starting parity; when the counts are equal, take the cheaper of the two possibilities.

- **Time:** O(n)
- **Auxiliary space:** O(n)

### 2245 — Maximum Trailing Zeros in a Cornered Path

Count the factors of 2 and 5 in every grid cell, since the number of trailing zeros is the minimum of the two factor counts. Build row and column prefix sums so the factor counts for each of the four possible cornered paths (up-left, up-right, down-left, down-right) can be calculated in O(1). Check every cell as the turning point and keep the maximum trailing-zero count.

- **Time:** O(m × n)
- **Auxiliary space:** O(m × n)

### 3381 — Maximum Subarray Sum With Length Divisible by K

Use prefix sums grouped by their index remainder modulo k. A subarray from prefix index l to r has a length divisible by k exactly when l % k == r % k. For each remainder, store the smallest prefix sum seen so far. Subtracting that minimum from the current prefix sum gives the maximum valid subarray sum ending at the current index.

- **Time:** O(n)
- **Auxiliary space:** O(k)

### 3169 — Count Days Without Meetings

Sort the meeting intervals by their start day and merge overlapping or adjacent intervals. For every merged interval `[start, end]`, the number of occupied days is `end - start + 1`. Subtract the total occupied days from `days` to get the number of days without meetings.

- **Time:** O(n log n)
- **Space:** O(1) extra space apart from sorting

### 2831 — Find the Longest Equal Subarray

Group the indices of each distinct value. For one value, use a sliding window over its occurrence indices. If the window contains `right - left + 1` occurrences, the number of other elements that must be deleted is `pos[right] - pos[left] - (right - left)`. Shrink the window whenever this exceeds `k`. The number of occurrences in the largest valid window is the answer for that value.

- **Time:** O(n)
- **Space:** O(n)

### 1861 — Rotating the Box

First simulate gravity before rotating the box. After a 90-degree clockwise rotation, the original horizontal direction becomes the direction of gravity, so each row can be processed independently from right to left. Keep an `empty` pointer at the rightmost available position; stones move to this position, while obstacles reset the available position to the cell immediately before them. After all stones have fallen, rotate the matrix clockwise by mapping `(r, c)` to `(c, m - 1 - r)`.

- **Time:** O(m × n)
- **Auxiliary space:** O(m × n) for the rotated result

### 1492 — The kth Factor of n

Check divisors only up to `sqrt(n)`. Whenever `i` divides `n`, both `i` and its paired factor `n // i` are factors. Store the factors, sort them in ascending order, and return the `k`th one if it exists; otherwise return `-1`.

- **Time:** O(√n log √n)
- **Auxiliary space:** O(√n)

### 2087 — Minimum Cost Homecoming of a Robot in a Grid

Move directly toward the home position: first traverse the required rows and then the required columns. Every vertical move enters a row and costs that row's `rowCosts` value; every horizontal move enters a column and costs that column's `colCosts` value. There is no benefit to detouring because all movement costs are non-negative, so the direct path is optimal.

- **Time:** O(|startrow - homerow| + |startcol - homecol|)
- **Auxiliary space:** O(1)

### 3 — Longest Substring Without Repeating Characters

Use a sliding window with two pointers and a dictionary storing the latest index of each character. When a duplicate character appears inside the current window, move the left pointer just after its previous occurrence. Track the maximum window length throughout the scan.

- **Time:** O(n)
- **Auxiliary space:** O(n)

### 3896 — Minimum Operations to Transform Array into Alternating Prime

Precompute prime numbers with the Sieve of Eratosthenes. At even indices, the value must be prime, so find the smallest prime greater than or equal to the current value and add the required increments. At odd indices, the value must be non-prime: an existing non-prime costs 0 operations, prime `2` costs 2 operations (`2 → 3 → 4`), and every other prime costs 1 operation because adding 1 produces an even number greater than 2.

- **Time:** O(M log log M + n log M), where M is `max(nums) + 100`
- **Auxiliary space:** O(M)

### 3756 — Concatenate Non-Zero Digits and Multiply by Sum II

Precompute three prefix arrays: the sum of non-zero digits, the number of non-zero digits, and the numeric value formed by concatenating non-zero digits. For a query `[left, right]`, subtract the prefix values to get the digit sum and count in the range. Use the count to remove the digits before `left` from the concatenated value with modular exponentiation, then multiply the resulting number by its digit sum modulo `10^9 + 7`.

- **Time:** O(m + q log m), where m is the string length and q is the number of queries
- **Auxiliary space:** O(m)

### 3719 — Longest Balanced Subarray I

Enumerate every starting index and extend the subarray one element at a time. Maintain separate sets for distinct even and odd values, adding each new value to the appropriate set. Whenever the two set sizes match, update the maximum subarray length. Sets ensure repeated values are counted only once.

- **Time:** O(n²) average, since there are O(n²) subarrays and set insertion is O(1) average
- **Auxiliary space:** O(n) for the two sets

### 893 — Groups of Special-Equivalent Strings

For each word, separate the characters at even and odd indices, then sort each group. Use the pair of sorted groups as a tuple signature and add it to a set. Words with the same signature are special-equivalent because characters can be rearranged freely within their respective index parity groups. The number of unique signatures is the number of groups.

- **Time:** O(N × K log K), where N is the number of words and K is the length of each word
- **Auxiliary space:** O(N × K) for the stored signatures

### 1405 — Longest Happy String

Use a max heap (implemented with negative frequencies) to repeatedly select the character with the largest remaining count. If selecting it would create three identical consecutive characters, use the next most frequent character instead and put the first character back into the heap. Stop when no valid alternative remains.

- **Time:** O((a + b + c) log 3), effectively O(a + b + c) because the heap contains at most three characters
- **Auxiliary space:** O(a + b + c) for the result; O(1) for the heap

### 2109 — Adding Spaces to a String

- **Auxiliary space:** O(n + m) for the result list and output string

### 606 — Construct String from Binary Tree
